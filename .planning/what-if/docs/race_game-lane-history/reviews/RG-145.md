## Findings for the follow-up (not rework)
1. **The cost anchor in §4 is weak, and the doc already labels it O.** The increments are sized from the Gunsai Low→Medium→High deltas, but those deltas are mostly preset costs (shadow cascades, MSAA, render scale), not texture reads. §3.2 says the same thing differently: "Medium already costs +4.5 ms on Gunsai with its existing samples". Read §4 as an ordering, not a budget. T1 (ms per texture read on the WorldGen ground) is the first GPU ticket and replaces it.
2. Stochastic and hex tiling are described from general knowledge (O). The papers were not read. That is acceptable for ranking; read the papers when T4 is written.
3. The useful structural findings, all verified:
   - `Kn5Multilayer` is already a 4-layer control-map splat, without vertex colour;
   - the road ribbons carry arc-length UVs, while junction patches and fills have zero UVs and will smear once textured;
   - texture arrays cannot be mip-streamed;
   - decals break the SRP Batcher.
   These shape the first implementation ticket.
