## Decisions (What If mandate: adjust with a justification, report here + handover)
1. **Land drive path accepted as the b1/b3 path.** RG-172's path (face 0 row 670) is open ocean on the surface base, so no region world is built and the build cost is invisible. `DriveLand` keeps the shape (3 region borders + 1 cube edge, 4x speed, 300 s) over the block B regions of RG-169 (100 % land). The ocean path stays available (`-Modes drive`) and passed after the change too (P95 0.778 ms, 0 holes).
2. **Region build time is now the arithmetic of `VerticalCurves`** (~99 % of 8-28 s per region; `VcWorkBudget` 600 M updates). Cutting it changes the profile output, i.e. the NightRacer golden hash — that is a NightRacer WorldGen output change, not a What If-only change. Follow-up candidate (not created yet): either (a) a planet-only cheaper vertical-curve setting passed through the spec (golden hash for NightRacer unchanged; planet outputs re-baselined under the What If mandate), or (b) early-exit/convergence improvement that stays bit-identical where it can. Prefer (a). Not urgent: prefetch covers it at 4x (min lead 25 s); thin margin with a 49 s build.
3. Gen0 baseline built by temporarily switching one call to the allocating overload (not a git-history rebuild) — accepted, that overload allocates exactly what the old `Clone` did.
