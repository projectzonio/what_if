## Scope
1. `src/WhatIf.WorldGen/Scatter.cs` (new): `Instance` (Kind, Variant, X, Y, Z, Yaw, Scale), `ScatterModel` built from (spec, `GenResult`), `Sector(sx, sz)` returns that sector's instances, `Hash(...)` over a window. Pure function of (seed, sector, terrain, roads, settlements); RNG stage `"scatter" + sx + "," + sz`; no state shared between sectors (§4 first row). Kinds v1: tree, bush (forest-edge band), house, street tree.
2. Rules from §4 with its values: forest mask (fBm, 500 m, > 0.15), slope, height band, road clearance (+10 m primary, +6 m local, from half width), curve sight term, spans/holes/viaduct piers, village lots (22 m frontage, 6 m setback, 9 x 11 m, junction 14 m), street trees, forest/settlement separation (40 m, 60 m fade), caps (1500 trees, 150 buildings per sector, deterministic thinning). Values are O: tune them only from the dump, and write every change with its reason.
3. `Generator.cs`: expose settlements read-only on `GenResult` (centre, radius, city/village). The road dataset hash must not change; `Export.cs` stays untouched.
4. CLI `--scatter-dump <file> [--window x0,z0,size,step]`: `scatter.csv` (`kind,variant,x,y,z,yaw,scale,sector_x,sector_z`) + `scatter-hash.txt`; prints checks (a)-(d) from §5 and per-sector placement ms (`Stopwatch`; min/median/max over the seed-1 window). Over 1 ms per sector: say so and propose the two-pump split (§5), do not build it.
5. Unit tests for (a)-(c), determinism (two runs, same hash; a sector computed alone equals the same sector computed among neighbours) and the unchanged road hash.
6. `render_net.py`: optional instance overlay from `scatter.csv` (trees/bushes/houses in distinct colours). One PNG of the tile window into the outbox: village 3 and the straight visible.
