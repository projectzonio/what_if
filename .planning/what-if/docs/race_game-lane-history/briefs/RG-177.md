## Why
User, 2026-11-15, verbatim: „Co použít silnice a souřadnice jako kotvy, systém dlaždic zahodit a dogenerovat svět?“ and on the decision: „vyzkoušet, změřit, určit postup na základě dat, ne odhadů.“

Today every level-10 region (~10 km) is an independent WorldGen world (`RegionWorld.BuildSurface`): own city, own motorway edge to edge, roads end at region borders, 32 m taper on the border. The proposal (direction doc §4, option B) replaces this by global anchors: settlements on the planet surface + a road network in double 3D, split into 2-5 km segments with pinned joint heights. This ticket builds the **minimal** anchor prototype and measures both variants with the same rows. It does not decide; RG-178 adds sectors and evaluates the decision rule. Report failures as failures — a spike that shows B is worse is a valid result.

## Scope
1. New Unity-free library `src/WhatIf.Planet.Anchors` (netstandard2.1, like the other WhatIf libraries) + console `src/WhatIf.Planet.Anchors.Experiment` + tests `tests/WhatIf.Planet.Anchors.Tests` (register in `scripts/test.ps1` and `NightRacer.sln`) + runner `tools/whatif-anchors/run-anchors.ps1` (measure lock with a wait loop, raw data git-ignored under `artifacts/whatif-anchors/<stamp>/`, like `tools/whatif-planet/run-experiment.ps1`).
2. **Settlements (A1):** pure function of (world seed, cell id). Land only (not Ocean/Sea/Lake/Beach), slope limit, class city/town/village from the surface (dry area, coast, flatness). Pick the cell level and density yourself; report the density next to variant A's on the same area.
3. **Network (A2 topology):** which settlement pairs get a road — must be decidable from settlements within a bounded neighbourhood (state the radius), never from the whole planet. Class motorway / primary / secondary from settlement classes.
4. **Routing:** surface-aware, deterministic (fixed tie-break), water forbidden in the spike (bridges later; report corridors that cannot be routed), slope cost. Coarse route on a lattice level of your choice, then horizontal fillets to the class minimum radius in a local gnomonic chart of the segment.
5. **Segments + profile:** 2-5 km segments; joint height pinned = a pure function (e.g. surface height at the joint, settlement entrance height), so each segment's vertical profile solves alone. Reuse the WorldGen vertical-curve solver through an **additive** public entry in `WhatIf.WorldGen` (default `Generator` path bit-identical: golden tests + RG-175 hash test unchanged).
6. **Measurement area:** 5 x 5 level-10 regions around the block A centre and around the block B centre (B covers a cube vertex). Both variants on exactly the same area.
7. Out of scope: terrain carve, sector meshes, settlement street content, bridges, runtime (all RG-178).
