## Why
WI-ADR-001 is Accepted: the planet is cut into deformed level-15 quads (216-306 m sides) with a face-wide integer vertex lattice, seamless by construction. WorldGen (`src/WhatIf.WorldGen`) generates on a flat square map with a map-local noise (`Natural`, per-map permutation from `spec.Seed`). The user chose (2026-11-12 ~16:40, via AI dohled) the next step: **an adapter that feeds one deformed planet sector into WorldGen**, so the existing generator produces the near terrain of a planet sector. CPU only, numbers, no Unity, no rendering.

## Design (simplest thing that answers the questions)
1. **New Unity-free library `src/WhatIf.Planet.WorldGen/`** (netstandard2.1, references `WhatIf.Planet` + `WhatIf.WorldGen`). Neither existing library references the other; the adapter is the only bridge.
2. **`SectorPlanetInput` v1** (subset of the RG-160 record): `SectorId`, frame (centre double3, up/east/north from `QuadSector`), `baseHeightM[19][19]` at 16 m spacing in the sector's local tangent plane (17 x 17 interior + 1-sample apron) sampled from `PlanetNoise.Height` at **global positions** (direction of the local point, never a sector-local seed), `regionSeed` derived from the sector id + world seed. Skip biome, coast, settlements, corridors, portals (later tickets) — say so in the doc.
3. **One additive hook in `TerrainModel`** (`src/WhatIf.WorldGen/Terrain.cs`, the only NightRacer file you may change): an optional base-height provider (e.g. `Func<double,double,double>` or a small interface) that, when set, replaces the low-frequency part of `Natural` (hills envelope + mountain) while WorldGen keeps its detail + carving on top. **Null = current behaviour, bit-identical** (all `tests/WhatIf.WorldGen.Tests` pass unchanged; add one test that a model without the provider gives the same `Height` as before at a fixed seed/sample set).
4. **Adapter build of one sector:** for each of the 65 x 65 lattice vertices of the deformed quad, map its direction to the sector's local tangent plane (x, z double), evaluate WorldGen height there (base from planet + WorldGen detail/carve), and place the vertex at `dir * (R + h)`. WorldGen's own contribution (everything above the planet base) is multiplied by a **border taper** that is 0 on the quad edge (start with 32 m, report the value used), so neighbour sectors with different local frames meet exactly on the planet base (RG-160 rule 3).
5. **Experiment rows** in `WhatIf.Planet.Experiment` as a new check group `w` (same CSV columns, protocol/diag kinds), run by `run-experiment.ps1` — sectors chosen as in (a): one face centre, one cube-edge midpoint, one cube vertex, plus 3 seeds:
   - **w1** shared-edge base-height samples between neighbour sectors (incl. across a cube edge and at a cube vertex): max |diff| m, **= 0 (bit-identical)**, protocol.
   - **w2** seam: shared edge vertices of the final adapted mesh from both sectors, max world gap mm, **< 1 mm**, protocol.
   - **w3** taper: max slope added by the taper (rise/run of the WorldGen contribution inside the taper band), report; and max |WorldGen contribution| at the edge (must be 0), protocol.
   - **w4** planar distortion: for each of the three sectors, the quad's footprint in its tangent plane (side lengths, max angle deviation from 90°, area vs 256 x 256), report — this is the input for how WorldGen's square domain covers a deformed quad.
   - **w5** cost: adapter build of one sector (input + 65 x 65 heights), median/P95 ms of 3 runs single thread, threshold **< 3 ms** (streaming `BudgetMs`), protocol; report the WorldGen `TerrainModel` construction time separately.
   - All earlier rows (a)-(d), r1-r5 must stay PASS; a/b/c + r1 bit-identical to main's `what-if-planet-experiment.csv`.
6. **Doc** `.planning/race-game/docs/what-if-planet-worldgen-adapter.md` (short): what the adapter does, the hook, the taper value, the w-table, what v1 leaves out (biome/coast/settlements/corridors/portals/road continuity, carved-road taper vs road height hint) and the recommended next step. Also overwrite `what-if-planet-experiment.{md,csv}` (incl. the existing RG-164 "Metric change" note — the generator drops it; carry it over or make the generator emit it).
7. If a w-row fails, report FAIL with numbers and a cause; do not tune thresholds. Under the What If mandate the orchestrator decides at review.
