## Design (simplest thing that meets the rows; you may improve it, say why in the outbox)
1. **Base = surface.** `RegionWorld` takes the base from `PlanetSurface.Height(dir)` (one `PlanetSurface` per thread, constructor 10-40 ms) instead of `PlanetNoise`; keep a switch so the old base still runs for rows a/b/c/r/e1-e4 comparisons. A region whose every lattice sample of a coarse 17 x 17 probe is Ocean/Sea gets **no WorldGen world** (sector = surface heights only); count such regions.
2. **Base evaluated once per point (RG-170 decision B).** Today the carve's `Natural` evaluates the base again through the `baseHeight` hook. Pass the pass-1 base values into the carve: additive `TerrainModel.HeightBatch(xs, zs, count, outH, baseH)` overload (or equivalent) — output bit-identical to the hook path when the same function feeds both (unit test). `Height`, `HeightWith`, `SampleTile`, `Hole` unchanged; golden hash unchanged.
3. **Water mask for WorldGen.** Additive `Generator.Run(spec, rules, baseHeight, isWater)` overload (`Func<double, double, bool>`, null = bit-identical, golden hash test). Settlement/house candidates on water are rejected; a road edge with any sample on water (every 16 m along the edge) is dropped; the existing connectivity step then works on what is left — simplest first, no bridges. `isWater` = surface kind Ocean/Sea/Lake at the chart point (Beach counts as land).
4. **Forest feeds scatter.** Additive optional density multiplier on `ScatterModel` (`Func<double, double, double>`, null = bit-identical): the planet `Forest` (0..1) multiplies the WorldGen mask — multiply, do not replace; water -> 0.
5. **Coast structure (RG-168 finding: the coast is a straight beach line across a whole region).** In `src/WhatIf.Planet.Surface`, add coast detail at 1-4 km (e.g. an extra domain-warp octave of the continent field that is strong only near the sea threshold). s1-s6 keep passing; s3 speckle < 5 % of land.
6. **Surface optimisation (RG-168 decision 1).** Options from the review: 2 warp octaves -> fewer interpolations; coarse-field reuse per sector row only when bit-identical to `Height`; skip detail octaves below the sample spacing. Measure before/after in the s7 row.
7. **Block experiment.** Pick deterministically (seed 1, search over the surface, ids reported): block A = 3 x 3 level-10 regions with coast + at least one lake; block B = 3 x 3 regions across a cube edge. Build all 18 regions, run e1-e4 seams across all inner region borders with the surface base, then the sector sweep. PNG top views per block (surface kind + roads + settlements + tree density), sha256 in the doc.
