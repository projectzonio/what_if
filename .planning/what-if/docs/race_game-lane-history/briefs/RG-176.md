## Why
A land region whose city cannot find a dry site gets **no WorldGen world** (`RegionWorld.NoSite`): only surface heights, 0 km of road. Block A of `run-experiment.ps1` (seed 1) has two: **A1 `F2.L10.r605.c682` (27 % land)** and **A8 `F2.L10.r607.c683` (35 % land)** (rows p2 in `.planning/race-game/docs/what-if-planet-experiment.md:683/690/692`). The user's overnight mandate wants the planet filled (tiles multiplied, forests, lakes, sea); empty coastal land is the visible gap. A coastal region with a few villages and roads between them is what a real coast looks like.

## Design (simplest first; you may improve it, say why in the outbox)
1. **`WorldSpec.Motorway` (bool, default true = today).** With false: `BuildMotorway` and `BuildInterchange` do nothing; `_set[0]` is a village-sized settlement (radius from the spec, e.g. `CityRadiusM` set to 350-500 by the caller) placed at `Spec.City`; villages and `ConnectPrimary`/`ConnectSecondary` run as today (every settlement joined, roads checked against the water mask). Check every place that reads the motorway/interchange result (`_mw`, ramp pins, `PR.RampPin`, `MotorwayEntry/Exit`) and guard it — no exception path for a missing motorway.
2. **`RegionWorld.BuildSurface` fallback:** after the 4 city attempts fail and before `NoSite`, set the village-only spec (`Motorway = false`, small radius) and retry `PickCity` + `Generator.Run` (the smaller radius finds dry sites on 27 % land). Still nothing -> `NoSite` as today. A region that already gets a city world is untouched (its spec, hash and roads bit-identical).
3. Rerun `tools/whatif-planet/run-experiment.ps1` (blocks A/B p-rows); add a row: land regions (>= 25 % land) without a world, before/after.
