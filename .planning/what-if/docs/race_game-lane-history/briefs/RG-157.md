3. **Cost on UHD:** what these assets would cost as LOD0 near the camera against RG-154's measured numbers (M) — tris, draw calls, alpha-test overdraw, shadow casters if enabled; O with formula. Note what a cutout leaf material means for the RG-154 "no shadow caster" choice.
