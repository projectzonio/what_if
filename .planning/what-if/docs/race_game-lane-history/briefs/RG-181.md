## Scope
1. **Meander / surface-aware routing.** Keep A* + slope/water cost; replace "string pull to a chord" by a deterministic rule that keeps the road on the terrain: e.g. pull only while the pulled line stays within a height/grade tolerance of the surface, then fit class-radius arcs; plus a low-amplitude deterministic meander (seeded by the edge key, never by request order) where the terrain is flat. Choose and justify.
2. **Feasible joints.** Before solving a segment profile, choose joint heights/grades so the segment can satisfy the class crest/sag radius within the cut/fill bounds (e.g. joint height from a smoothed ground profile along the route, grade from the neighbouring joint heights, clamp to class max grade). A segment that still needs the stall exit is counted, not hidden.
3. Settlement entrances, town/city street content = B3 (not here).
