2. **Corridors do not enter the street network.** A corridor runs to the settlement centre at the centre's surface height (`Corridor.cs:215`); inside radius + `BlendM` the sector blends the settlement's own terrain, then carves the nearest corridor over it (`AnchorSector.cs:12-60`). The corridor and the streets are two unrelated road systems overlapping in the town.

## Mechanism (orchestrator's proposal — the simplest that meets the rows; deviate only with a reason in the outbox)
1. **Class decoupled from motorway (WorldGen, additive):** a new `WorldSpec` field (e.g. `bool? CentreIsCity`, null = today's `Motorway`) sets `IsCity` of `_set[0]`. Default null -> NightRacer bit-identical.
2. **Pinned entrances (WorldGen, additive):** `WorldSpec.Entrances` (list of: point in the settlement chart, inward direction, pinned height, road class; default empty = today). The generator adds one road per entrance from the entrance point to the nearest street node (or the centre when no street is closer), with the entrance class width, and holds the first station at the pinned height and direction. Reuse the existing road builder / vertical profile path; if the profile solver cannot pin an end height today, add the pin the smallest way and say how.
3. **SettlementWorld:** town/city -> `CentreIsCity = true`; entrances = for every routed corridor that ends at this settlement, the corridor station where it crosses radius R (chart position, inward direction, profiled height, class). This makes the settlement world depend on its links: keep it a pure function of (seed, settlement, its link set) — the link set is already decidable from settlements in the layer radius.
4. **Corridor inside the settlement:** the corridor ends at its entrance station; `AnchorSector` stops carving the corridor inside R (the settlement world's entrance road takes over). The corridor's pinned end joint becomes the entrance height (surface height at the entrance point, grade as RG-181's entrance rule) instead of the centre height.
5. Settlement worlds stay lazy and cached in `AnchorWorld`; the cold sector budget below holds.
