## Mechanism (recommended; deviate only with a measured reason)
- **Shader:** one small URP shader `WorldGenScatter.shader` in `Assets/Scripts/Streaming/Resources/` (shipped through Resources, no global setting), modelled on `Assets/Kn5/Shaders/Kn5Grass.shader` (already instanced): albedo = vertex colour (trunk/crown, wall/roof) x a per-instance tint from a hash of the instance position (`unity_ObjectToWorld` translation) — so the 4 colour variants cost **no** extra draw call; main light Lambert + ambient SH + fog. `Material.enableInstancing = true`. No ShadowCaster pass needed (V3).
- **Meshes:** built once at start in C#: tree LOD1 ~60 tris (hex crown + trunk), tree LOD2 ~12 tris, bush ~24, house ~24 (box + gable roof). Scale from `Instance.Scale`, yaw from `Instance.Yaw`.
- **Batches:** one batch family per kind x LOD for the **whole active ring**, not per sector: every 16 m of camera movement (or LOD ring crossing) concatenate the matrices of the visible sectors (sector-bounds frustum test) into per-kind/LOD arrays and draw them with `Graphics.RenderMeshInstanced` in chunks. RG-149 §2 left the per-call instance limit (1023 / 511) as **O** — check it on the 6000.3 script-reference page or by test, use the safe value, write which. Expected about 4-8 draw calls at Low instead of 36 (§7's dominant term).
- **Data:** instances belong to the sector `Content`, produced in the pure-data step (`StepCore` case 0 in `WorldGenSectorSource.cs`); dropped with the sector (memory `chunked-loading-always`, no whole-map array). Instances come from `ScatterModel.Sector(sx, sz)` (one `ScatterModel` per world, built from the same `WorldSpec` + `GenResult`; read-only API).
- **Frame budget of the build:** RG-151 measured placement 0.3-0.4 ms median but **4-11 ms cold** for village and dense forest sectors (first call builds the village lot list; JIT). `SectorStreamer.BudgetMs` is 3. Pre-warm the lot lists of all villages once during load (before the ride starts), and if a sector still takes > 3 ms, split it over two pumps (trees + bushes, then lots + street trees). The `_lots` cache in `ScatterModel` is a plain `Dictionary`: call it from one thread only (or lock).
- **Forest density:** the mask gives 24 % forest (design said 40 %). Leave `MaskOffset` 0 unless the shots look sparse; then pass `--worldgen-scatter-mask 0.15` (optional flag, set `ScatterModel.MaskOffset`) and say so.
- Out of scope: shadows, LOD0, billboards, grass, wind (V3); houses in the city (V1 has none); CC0 models.
