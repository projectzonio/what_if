## Design (orchestrator — the simplest thing that meets the acceptance)
- **`QuadSector`** (replace `SectorFrame`/`SectorId`; delete the old planar-grid code and its experiment paths, do not keep both): `SectorId = (face, row, col)` at level 15 (`row`, `col` in [0, 2^15)); `Region => (face, 10, row >> 5, col >> 5)`.
- **Vertex lattice:** integer `(face, I, J)`, I, J in [0, 2^21] (64 intervals per sector). `a = I / 2^20 - 1` (exact in double), `u = tan(pi/4 * a)`, `dir = normalize(N + u U + v V)`. Per sector compute the 65 `u` and 65 `v` once (separable), not per vertex.
- **Canonical vertex rule:** a lattice point with I or J in {0, 2^21} lies on a cube edge or corner; map it through the neighbour table to every face that shares it and evaluate it on the **lowest face index**. Then any two sectors that share a vertex get identical double bits. (tan(pi/4) is not exactly 1 in double — that is why the rule exists; test it.)
- **Sector build:** world `dir * (R + h)` in double, `h = PlanetNoise` at `dir * R`; mesh data = float local position relative to the sector centre in the sector's own tangent frame (origin = centre direction * R, up = radial, east = face U projected) — row 1 unchanged.
- **Deformation report** (no threshold, report only): over all 4·2^15 sectors along one face diagonal and one face edge row plus the 8 × 3 corner sectors: edge length min/max (m), interior corner angle min/max (deg), area max/min, vertex spacing min/max. Prediction (O, ADR §7): ~306 m along the axes, ~256 m at the corners, area 1.41:1, one 120° corner at each cube vertex.
- **Roads (RG-160 §4, corridors only):**
  - Settlements: deterministic from worldSeed (SplitMix64), about one per (100 km)^2 on the whole sphere (~51 000; no land mask), as double unit vectors. Edges: each node to its 3 nearest (cell hash on the level-6 quadtree is enough; spherical Delaunay = 3D convex hull only if it stays inside r5's budget). Edge = great-circle arc, class motorway/primary.
  - Portal: `borderId` = (face, level 10, row, col, side) canonicalised from the lower `RegionId` side; `p = normalize(n_road × n_border)` with the sign toward the road direction; `s` = arc length from the border's canonical start vertex, **quantised to 1 cm as int64**; `angle` = heading relative to the border tangent. Snap: a portal closer than 256 m to a region vertex moves along the border (and the road bends to it).
  - Refinement for r4: inside one corner region (three faces meet), a corridor that enters through one portal, turns at a junction node and leaves through another: arcs sampled at 4 m in the region's frame, the turn filleted with the class minimum horizontal radius — **motorway 344.83 m, primary 121.31 m** (M, `artifacts/worldgen/world-rules.json` `classes.<c>.radius.min_radius_m`, sha256 `24c9a9c6…c723`; hard-code the two values with this source in a comment, do not read the git-ignored file).
