## Design (orchestrator's sketch — the simplest thing that runs §4)
- `src/WhatIf.Planet/` — netstandard2.1, `Nullable`/`ImplicitUsings` disable like WorldGen (C# 8), **no project or package references**, double math, no clock, own SplitMix64 if randomness is needed (System.Random differs across runtimes):
  - `CubeSphere` — direction <-> (face, u, v) with equal-angle warp both ways; `RegionId (face, level, row, col)`; neighbour lookup across the 12 edges and at the 8 corners (with the 90° rotations).
  - `Frame` — double position on the sphere, (up, north/east) tangent basis, **parallel transport** along a step (rotation about the axis up0 × up1).
  - `SectorFrame` — tangent frame of a 256 m sector from **its own centre** (WI-ADR-001 row 3): local (x, z) metres -> world double position (planar point dropped onto the sphere along the radial, height above sphere added); `SectorId (RegionId, ix, iz)`.

## Checks and thresholds — exactly RG-155 §4 (do not relax)
| # | PASS when |
|---|---|
| a | shared-edge mismatch over all 4-neighbour sector pairs in a 5×5 block **and** the sectors around a region-border vertex and a cube-corner vertex: max vertical < 1 mm **and** max horizontal < 1 mm |
| b | 10^6 points per region from origin A, origin B 256 m away and an origin 100 km away: 0 differing bits for the same double world x; if x is rebuilt as origin + local, report the differing count and require ≤ 1 float ulp |
| c | 1 km-radius loop at lat 89.99° (1 m steps) and a closed 1 km loop over a cube corner: per-step rotation vs analytic < 1e-9 rad, no step > 2× median, closing holonomy = enclosed area / R² within 1e-9 rad (spherical cap: area = 2πR²(1 − cos(r/R))) |
| d | 1000 sectors per region, 65×65 vertices, height + frame, single thread, Release, warm: median ≤ 0.5 ms/sector, P95 ≤ 3 ms; CPU share at 900 km/h / 5 km (38 sectors/s) < 2 % of one core |

- Output table: `check | region | seed | metric | measured | threshold | pass`; hardware line (CPU model, power mode), commit SHA, wall time. **An `n/a` cell is a FAIL of the protocol.**
- A FAIL is reported as FAIL with the §4 decision rule applied (what it means for WI-ADR-001) — never tune a threshold, never mark a failed check passed. If a threshold itself looks wrong (e.g. (a) horizontal at a cube corner is geometrically impossible under row 3), write the evidence in the outbox under "Decisions for the orchestrator"; the orchestrator decides, the acceptance stays as written.
- Check (a) at region/corner borders is the real question of WI-ADR-001 row 3 ("a sector takes its frame from its own centre"): two sectors with different tangent frames share an edge only if their planar edge points map to the same sphere points. Measure it honestly; RG-155 predicted ~0 vertical, horizontal was not predicted.
