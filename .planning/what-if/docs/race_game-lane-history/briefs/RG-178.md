## Decision rule (fixed 2026-11-15, orchestrator; evaluate, do not tune)
- **B** when all hold: n1(B) = 0; n2(B) >= max(n2(A), 95 %); s1 = 0; s2 bits 0 and footprint not worse than A; s3 P95(B) <= 1.25 x P95(A); s5 median(B) <= median(A); s4 B <= 2 x A; s6 t1 P95 <= 1.0 ms and holes 0.
- **B + optimisation ticket** when only cost rows (s3, s4, s5, c1) miss, each by at most 2 x.
- **A (region portals)** when a network or seam row (n1, n2, s1, s2) fails for B, or a cost row misses by more than 2 x.
