   3. **Noise precision without GPU FP64** — CPU double authority + camera/tile-relative float on the GPU, integer-lattice/hashed noise, per-patch origin rebasing; what float32 precision gives at Earth radius (compute it, O with the formula).
   4. **VRAM / streaming budget on i3-1215U/UHD** — budget for planet patches + WorldGen sectors in shared memory, IO per km/h of travel at car / aircraft speeds; anchor on measured project numbers (perf-matrix RAM/load, RG-137/RG-141) as M, the rest O with the formula.
4. Short "what to take / what to avoid" list (≤ 10 rows) and a **next step** for What If (e.g. an ADR draft title + the one experiment that would decide it). No NightRacer implementation tickets.
