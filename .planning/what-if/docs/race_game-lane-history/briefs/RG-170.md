## Design (simplest exact mechanism)
1. **Batch height query in `TerrainModel`** (additive public API in `Terrain.cs`; `Height`, `HeightWith`, `SampleTile`, `Hole` unchanged bit for bit). Suggested shape: `public void HeightBatch(double[] xs, double[] zs, int count, double[] outH)` (or a small reusable `HeightQuery` object if that is cleaner). Two exact levers, measure each:
   - **(a) candidate-set reuse:** the per-point candidate set of `Height` depends only on the 64 m hash-cell range `floor((x +- pad) / 64)`, `floor((z +- pad) / 64)` (pad = `MaxDiffM * SlopeRun + ShoulderM + 12`). Points with the same range get the same set -> query + sort once per distinct range (a 65 x 65 sector has a few dozen). Use the same cell size as `_segIdx` (make 64 a named const in `Terrain.cs`; `Graph.cs` stays read-only).
   - **(b) exact pruning in the nearest-centreline loop:** skip a candidate whose segment bounding-box distance to the point is **strictly greater** than the current best distance (it cannot win; ties keep the `id < bestId` rule). Optionally visit candidates in increasing box distance. Must give exactly the same `bestId` as `HeightWith`.
   - Result must be **bit-identical to `Height(x, z)` for every point** — this is a refactor of the query, not a new carve.
2. **`SectorBuild.Build` uses the batch** (row or whole-sector batch, your choice); output bit-identical to RG-167's build.
3. **e10 on the worst sector:** new sweep row: build every sector of each site's region (32 x 32 = 1024 sectors per region, single thread, seed 1, one pass, untimed warm-up first) and report median / P95 / P99 / max ms + the slowest sector id; then the protocol rows time **the slowest sector of the sweep** (5 warm + 51 timed, 3 `ecost` processes) in addition to the current first-road sector. Keep the sweep inside the `ecost` processes or a separate mode so the (d) spread stays below 20 %.
4. **Tests:** `tests/WhatIf.WorldGen.Tests`: `HeightBatch` == `Height` bit for bit on a dense settlement world (>= 20 000 random points incl. points beyond road ends / at bends / in tunnel-portal zones) and the existing golden hash unchanged. `tests/WhatIf.Planet.Tests`: sector build v2 output with the batch == the RG-167 point-query build (keep the old path as a private reference or compare against `Height` directly).
